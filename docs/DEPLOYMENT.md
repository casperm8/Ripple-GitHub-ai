# Deployment Guide\n\n## Backend Deployment (Heroku)\n\n### Prerequisites\n- Heroku account\n- Heroku CLI installed\n- Git repository initialized\n\n### Steps\n\n1. **Create Heroku App**\n```bash\nheroku login\nheroku create ripple-api\n```\n\n2. **Set Environment Variables**\n```bash\nheroku config:set MONGODB_URI=your_mongodb_uri\nheroku config:set JWT_SECRET=your_jwt_secret\nheroku config:set CLIENT_URL=https://ripple-web.vercel.app\nheroku config:set NODE_ENV=production\n```\n\n3. **Deploy**\n```bash\ngit push heroku main:main\n```\n\n4. **Verify**\n```bash\nheroku logs --tail\n```\n\n## Web App Deployment (Vercel)\n\n### Steps\n\n1. **Install Vercel CLI**\n```bash\nnpm install -g vercel\n```\n\n2. **Configure .env**\n```bash\nVITE_API_URL=https://ripple-api.herokuapp.com\n```\n\n3. **Deploy**\n```bash\ncd web\nvercel\n```\n\n4. **Set Environment Variables in Vercel Dashboard**\n- VITE_API_URL: https://ripple-api.herokuapp.com\n\n## Mobile App Deployment (EAS)\n\n### iOS\n\n1. **Setup EAS**\n```bash\ncd mobile\nnpm install -g eas-cli\neas login\n```\n\n2. **Configure app.json with projectId**\n\n3. **Build**\n```bash\neas build --platform ios\n```\n\n4. **Submit to App Store**\n```bash\neas submit --platform ios\n```\n\n### Android\n\n1. **Build**\n```bash\neas build --platform android\n```\n\n2. **Submit to Google Play**\n```bash\neas submit --platform android\n```\n\n## Database Setup (MongoDB Atlas)\n\n1. **Create Account** at https://www.mongodb.com/cloud/atlas\n\n2. **Create Cluster**\n- Choose cloud provider and region\n- Click Create Cluster\n\n3. **Get Connection String**\n- Go to Clusters > Connect\n- Choose \"Connect your application\"\n- Copy connection string\n\n4. **Add IP Whitelist**\n- Go to Network Access\n- Add your IP or allow all (0.0.0.0/0)\n\n5. **Use Connection String**\n```bash\nMONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/ripple\n```\n\n## Domain Configuration\n\n### Custom Domain for Backend\n1. In Heroku Dashboard: Settings > Domains\n2. Add custom domain: `api.yourdomain.com`\n3. Point DNS to Heroku endpoint\n\n### Custom Domain for Web\n1. In Vercel Dashboard: Settings > Domains\n2. Add custom domain: `yourdomain.com`\n3. Follow DNS instructions\n\n## CI/CD Pipeline\n\n### GitHub Actions (Auto Deploy)\n\nCreate `.github/workflows/deploy.yml`:\n\n```yaml\nname: Deploy\n\non:\n  push:\n    branches: [main]\n\njobs:\n  deploy:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v2\n      \n      - name: Deploy Backend\n        run: |\n          git remote add heroku https://heroku:${{ secrets.HEROKU_API_KEY }}@git.heroku.com/ripple-api.git\n          git push heroku main:main\n        env:\n          HEROKU_API_KEY: ${{ secrets.HEROKU_API_KEY }}\n      \n      - name: Deploy Web\n        env:\n          VERCEL_TOKEN: ${{ secrets.VERCEL_TOKEN }}\n        run: |\n          cd web\n          npm install\n          npm run build\n```\n\n## Monitoring\n\n### Heroku Logs\n```bash\nheroku logs --tail --app ripple-api\n```\n\n### Database Monitoring\n- Use MongoDB Atlas Dashboard\n- Monitor: Query performance, storage, memory\n\n### Error Tracking\n- Consider using Sentry for error monitoring\n- Add to backend: `npm install @sentry/node`\n\n## Scaling\n\n### Backend\n- Upgrade Heroku dyno if needed\n- Enable auto-scaling\n- Use worker processes for background jobs\n\n### Database\n- Monitor collection sizes\n- Create indexes on frequently queried fields\n- Enable sharding if collection exceeds 100GB\n\n## Backup & Recovery\n\n### Database Backups\n```bash\n# Automated backups in MongoDB Atlas:\n# Go to Backup > Automatic Backup Schedule\n```\n\n### Restore from Backup\n```bash\n# Use MongoDB Atlas restore feature\n# Or export/import via mongodump/mongorestore\n```\n\n## SSL/TLS Certificate\n\n- Heroku provides automatic SSL\n- Vercel provides automatic SSL\n- For custom domains, use Let's Encrypt\n\n## Performance Optimization\n\n1. **Caching**\n   - Add Redis for session storage\n   - Cache featured codes\n\n2. **CDN**\n   - Use Cloudflare for assets\n   - Cache images and static files\n\n3. **Database Indexes**\n   - Index: `platform`, `owner`, `isActive`\n   - Index: `tags` for search\n\n4. **API Rate Limiting**\n   - Already configured in express-rate-limit\n   - Adjust based on usage patterns\n"
