# Ripple - Referral & Affiliate Code Sharing App

A cross-platform application for users to easily share, discover, and manage referral and affiliate codes with others.

## Features

- **Code Sharing**: Share referral/affiliate codes across multiple platforms
- **Discovery**: Browse and search available referral codes
- **User Profiles**: Build your referral network
- **Tracking**: Monitor code usage and earnings
- **Multi-platform**: Available on iOS, Android, Web, and Desktop
- **Social Integration**: Share codes via social media
- **Real-time Updates**: Instant notifications for code interactions

## Project Structure

```
├── backend/              # Node.js/Express API server
├── web/                  # React web application
├── mobile/               # React Native mobile apps (iOS/Android)
├── desktop/              # Electron desktop application
├── docs/                 # Project documentation
└── scripts/              # Development and deployment scripts
```

## Tech Stack

- **Backend**: Node.js, Express.js, MongoDB
- **Frontend (Web)**: React, Redux, Tailwind CSS
- **Mobile**: React Native, Expo
- **Desktop**: Electron, React
- **Real-time**: Socket.io
- **Authentication**: JWT, OAuth 2.0
